# 📡 Network Monitoring & Incident Analysis (NOC Simulation)

## 📌 Overview
This project simulates Network Operations Centre (NOC) activities, focusing on monitoring network incidents, analysing faults, and evaluating service performance.

## 🎯 Objectives
- Analyse network incident patterns
- Evaluate resolution times across alarm types
- Identify high-risk regions and recurring issues

## 🛠 Tools Used
- Microsoft Excel
- Data Analysis (Pivot Tables, Charts)

## 📊 Key Insights
- Critical alarms (e.g., link down) had the highest resolution time
- Lagos region recorded the highest number of incidents
- Power-related issues contributed significantly to downtime

## 📁 Project Structure
- data/ → raw incident dataset
- analysis/ → Excel analysis
- visuals/ → dashboard

## ⚠️ Note
This is a simulated dataset based on real-world telecom/NOC scenarios and does not represent any live network.
